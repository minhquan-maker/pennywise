# PennyWise brand kit

Vector sources are `.svg` (text already converted to outlines, so no fonts are needed); `.png` exports sit next to each one. Drag the SVGs into Figma — each stays editable as shapes.

| File | Use |
|---|---|
| `logo/pennywise-mark.svg` | Lime coin, forest ring — default mark |
| `logo/pennywise-mark-forest.svg` | Inverted mark for lime backgrounds |
| `logo/pennywise-lockup-light.svg` / `-dark.svg` | Mark + wordmark for white / forest backgrounds |
| `icons/app-icon-1024.svg` | iOS/Android app icon (full bleed, OS rounds corners) |
| `social/avatar-800.svg` | Profile picture |
| `social/banner-1500x500.svg` | X / LinkedIn cover |
| `social/og-image-1200x630.svg` | Link preview (Open Graph) |
| `palette.svg` | Colour swatches |

## Palette
Forest Ink `#163300` · Lime Voltage `#9FE870` · Linen Mist `#E2F6D5` · Fog `#E8EBE6` · Obsidian `#0E0F0C` · Positive `#2F5711` · Danger `#CB272F` · Warning `#A86100`

## Rules
- Lime is a fill (or text on forest), never text on white.
- Wordmark: Inter Black, tracking −4.5%. Headlines: Inter Tight Black, uppercase, tracking −3.5%.
- Keep clear space around the mark of at least half its diameter.
- Wordmarks here are outlined from Inter Black (the app itself uses Inter Tight).
